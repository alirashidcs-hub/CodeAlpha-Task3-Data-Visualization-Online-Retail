# Processed Data

`online_retail_prepared.csv` is generated by running `src/visualization.py`
(or the notebook). It is excluded from this package/repo due to its size
(~76 MB); regenerate it locally after placing the raw dataset in
`data/raw/`.

It contains the original 8 raw columns plus the engineered fields used
throughout this project: `IsCancelled`, `HasCustomerID`, `IsValidSale`,
`Revenue`, `Year`, `Month`, `Day`, `DayOfWeek`, `Hour`, `InvoiceMonth`.
